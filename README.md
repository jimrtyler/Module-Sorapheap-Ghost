# 👻 ម៉ូឌុលសុវត្ថិភាព Ghost
**ឧបករណ៍ពង្រឹងសុវត្ថិភាព Windows និង Azure ផ្អែកលើ PowerShell**

> **ការពង្រឹងសុវត្ថិភាពជាមុនសម្រាប់បំណត់ចុងក្រោយ Windows និងបរិយាកាស Azure។** Ghost ផ្តល់នូវមុខងារពង្រឹងផ្អែកលើ PowerShell ដែលអាចជួយកាត់បន្ថយវ៉ិចទ័រការវាយប្រហារទូទៅដោយការបិទសេវាកម្មនិងពិធីការមិនចាំបាច់។

## ⚠️ ការបដិសេធទំនួលខុសត្រូវសំខាន់

**ត្រូវការការធ្វើតេស្ត**: តែងតែធ្វើតេស្ត Ghost នៅក្នុងបរិយាកាសមិនមែនផលិតកម្មជាមុនសិន។ ការបិទសេវាកម្មអាចប៉ះពាល់ដល់មុខងារអាជីវកម្មស្របច្បាប់។

**គ្មានការធានាណាមួយទេ**: ទោះបីជា Ghost កំណត់គោលដៅលើវ៉ិចទ័រការវាយប្រហារទូទៅក៏ដោយ គ្មានឧបករណ៍សុវត្ថិភាពណាមួយអាចទប់ស្កាត់ការវាយប្រហារទាំងអស់បានទេ។ នេះគឺជាធាតុផ្សំមួយនៃយុទ្ធសាស្រ្តសុវត្ថិភាពគ្រប់ជ្រុងជ្រះ។

**ផលប៉ះពាល់ប្រតិបត្តិការ**: មុខងារមួយចំនួនអាចប៉ះពាល់ដល់មុខងារប្រព័ន្ធ។ ពិនិត្យមើលការកំណត់នីមួយៗដោយប្រុងប្រយ័ត្នមុនពេលដំឡើង។

**ការវាយតម្លៃវិជ្ជាជីវៈ**: សម្រាប់បរិយាកាសផលិតកម្ម សូមពិគ្រោះជាមួយអ្នកជំនាញសុវត្ថិភាពដើម្បីធានាថាការកំណត់ត្រូវតាមតម្រូវការរបស់អង្គការអ្នក។

## 📊 ទិដ្ឋភាពសុវត្ថិភាព

ការខូចខាតពី ransomware បានឈានដល់ **៥៧ ពាន់លានដុល្លារក្នុងឆ្នាំ ២០២៥**​ ជាមួយនឹងការស្រាវជ្រាវបង្ហាញថាការវាយប្រហារជោគជ័យជាច្រើនបានទាញយកប្រើសេវាកម្មមូលដ្ឋាន Windows និងការកំណត់រចនាសម្ព័ន្ធខុស។ វ៉ិចទ័រការវាយប្រហារទូទៅរួមមាន:

- **៩០% នៃឧប្បត្តិហេតុ ransomware** ពាក់ព័ន្ធនឹងការទាញយកប្រើ RDP
- **ភាពងាយរងគ្រោះ SMBv1** បានអនុញ្ញាតការវាយប្រហារដូចជា WannaCry និង NotPetya  
- **ម៉ាក្រូឯកសារ** នៅតែជាវិធីសាស្រ្តចម្បងនៃការចែកចាយមេរោគ
- **ការវាយប្រហារផ្អែកលើ USB** បន្តកំណត់គោលដៅបណ្តាញ air-gapped
- **ការប្រើប្រាស់ PowerShell ខុស** បានកើនឡើងយ៉ាងគួរឱ្យកត់សម្គាល់ក្នុងប៉ុន្មានឆ្នាំចុងក្រោយនេះ

## 🛡️ មុខងារសុវត្ថិភាព Ghost

Ghost ផ្តល់នូវ **មុខងារពង្រឹង Windows ចំនួន ១៦** បូកនឹង **ការរួមបញ្ចូលសុវត្ថិភាព Azure**:

### ការពង្រឹងបំណត់ចុងក្រោយ Windows

| មុខងារ | គោលបំណង | ការពិចារណា |
|----------|---------|----------------|
| `Set-RDP` | គ្រប់គ្រងការចូលប្រើ Remote Desktop | អាចប៉ះពាល់ការគ្រប់គ្រងពីចម្ងាយ |
| `Set-SMBv1` | គ្រប់គ្រងពិធីការ SMB ពីមុន | ចាំបាច់សម្រាប់ប្រព័ន្ធចាស់ណាស់ |
| `Set-AutoRun` | គ្រប់គ្រង AutoPlay/AutoRun | អាចប៉ះពាល់ភាពងាយស្រួលរបស់អ្នកប្រើ |
| `Set-USBStorage` | ដាក់កំហិតឧបករណ៍ផ្ទុក USB | អាចប៉ះពាល់ការប្រើប្រាស់ USB ស្របច្បាប់ |
| `Set-Macros` | គ្រប់គ្រងការប្រតិបត្តិម៉ាក្រូ Office | អាចប៉ះពាល់ឯកសារដែលបើកម៉ាក្រូ |
| `Set-PSRemoting` | គ្រប់គ្រង PowerShell remoting | អាចប៉ះពាល់ការគ្រប់គ្រងពីចម្ងាយ |
| `Set-WinRM` | គ្រប់គ្រង Windows Remote Management | អាចប៉ះពាល់ការគ្រប់គ្រងពីចម្ងាយ |
| `Set-LLMNR` | គ្រប់គ្រងពិធីការដោះស្រាយឈ្មោះ | ជាទូទៅមានសុវត្ថិភាពក្នុងការបិទ |
| `Set-NetBIOS` | គ្រប់គ្រង NetBIOS លើ TCP/IP | អាចប៉ះពាល់កម្មវិធីពីមុន |
| `Set-AdminShares` | គ្រប់គ្រងការចែករំលែកគ្រប់គ្រង | អាចប៉ះពាល់ការចូលប្រើឯកសារពីចម្ងាយ |
| `Set-Telemetry` | គ្រប់គ្រងការប្រមូលទិន្នន័យ | អាចប៉ះពាល់សមត្ថភាពនិទាន |
| `Set-GuestAccount` | គ្រប់គ្រងគណនីភ្ញៀវ | ជាទូទៅមានសុវត្ថិភាពក្នុងការបិទ |
| `Set-ICMP` | គ្រប់គ្រងការឆ្លើយតប ping | អាចប៉ះពាល់ការនិទានបណ្តាញ |
| `Set-RemoteAssistance` | គ្រប់គ្រងជំនួយពីចម្ងាយ | អាចប៉ះពាល់ប្រតិបត្តិការតុជំនួយ |
| `Set-NetworkDiscovery` | គ្រប់គ្រងការរកមើលបណ្តាញ | អាចប៉ះពាល់ការរុករកបណ្តាញ |
| `Set-Firewall` | គ្រប់គ្រង Windows Firewall | សំខាន់សម្រាប់សុវត្ថិភាពបណ្តាញ |

## 🚀 ការចាប់ផ្តើមលឿន

### ការវាយតម្លៃសុវត្ថិភាព
```powershell
# ផ្ទុកម៉ូឌុល Ghost
IEX(Invoke-WebRequest 'https://raw.githubusercontent.com/jimrtyler/Ghost/main/Ghost.ps1')

# ពិនិត្យមើលការតាំងពូជសុវត្ថិភាពបច្ចុប្បន្ន
Get-Ghost
```

### ការពង្រឹងមូលដ្ឋាន (ធ្វើតេស្តជាមុន)
```powershell
# ការពង្រឹងសំខាន់ - ធ្វើតេស្តក្នុងបរិយាកាសមន្ទីរពិសោធន៍ជាមុន
Set-Ghost -SMBv1 -AutoRun -Macros

# ពិនិត្យមើលការផ្លាស់ប្តូរ
Get-Ghost
```

### ការដំឡើងសហគ្រាស
```powershell
# ការដំឡើង Group Policy (បរិយាកាស domain)
Set-Ghost -SMBv1 -AutoRun -GroupPolicy

# ការដំឡើង Intune (ឧបករណ៍គ្រប់គ្រងដោយពពក)
Set-Ghost -SMBv1 -RDP -USBStorage -Intune
```

## 🔍 ព័ត៌មានលម្អិតមុខងារ

### មុខងារពង្រឹងចម្បង

#### សេវាកម្មបណ្តាញ
- **RDP**: រារាំងការចូលប្រើ remote desktop ឬធ្វើឱ្យ port ចៃដន្យ
- **SMBv1**: បិទពិធីការចែករំលែកឯកសារពីមុន
- **ICMP**: ការពារការឆ្លើយតប ping សម្រាប់ការស៊ើបអង្កេត
- **LLMNR/NetBIOS**: រារាំងពិធីការដោះស្រាយឈ្មោះពីមុន

#### សុវត្ថិភាពកម្មវិធី  
- **ម៉ាក្រូ**: បិទការប្រតិបត្តិម៉ាក្រូក្នុងកម្មវិធី Office
- **AutoRun**: ការពារការប្រតិបត្តិស្វ័យប្រវត្តិពីមេឌៀអាចដកចេញបាន

#### ការគ្រប់គ្រងពីចម្ងាយ
- **PSRemoting**: បិទសេសិន PowerShell ពីចម្ងាយ
- **WinRM**: បញ្ឈប់ Windows Remote Management
- **Remote Assistance**: រារាំងការតភ្ជាប់ជំនួយពីចម្ងាយ

## 🎯 ឧទាហរណ៍សេណារីយ៉ូវាយប្រហារ

ខណៈពេលដែល Ghost កំណត់គោលដៅលើវ៉ិចទ័រវាយប្រហារទូទៅ ការការពារជាក់លាក់អាស្រ័យលើការអនុវត្តនិងការធ្វើតេស្តត្រឹមត្រូវ:

### ការវាយប្រហារបែប WannaCry
- **ការកាត់បន្ថយ**: `Set-Ghost -SMBv1` បិទពិធីការដែលងាយរងគ្រោះ
- **ការពិចារណា**: ធានាថាគ្មានប្រព័ន្ធពីមុនណាត្រូវការ SMBv1

### Ransomware ផ្អែកលើ RDP
- **ការកាត់បន្ថយ**: `Set-Ghost -RDP` រារាំងការចូលប្រើ remote desktop
- **ការពិចារណា**: អាចត្រូវការវិធីសាស្រ្តចូលប្រើពីចម្ងាយជំនួស

### មេរោគផ្អែកលើឯកសារ
- **ការកាត់បន្ថយ**: `Set-Ghost -Macros` បិទការប្រតិបត្តិម៉ាក្រូ
- **ការពិចារណា**: អាចប៉ះពាល់ឯកសារដែលបើកម៉ាក្រូស្របច្បាប់

### គ្រោះថ្នាក់ដែលបញ្ជូនដោយ USB
